# A币圈小工具

A币圈小工具是一款面向 Windows 10/11 64 位电脑的综合桌面工具箱，集 **ETH 行情研究、AI 辅助分析、资源与搜索、下载工具、图片视频处理、网络与局域网工具、效率工具** 于一个客户端中。

当前正式版本：**V1.1.0**

> 本仓库仅用于发布正式安装包和便携版，源码不公开。

## 主要功能

### 1. ETH 研究与行情监控

软件内置独立的 ETH 轻量研究工作台，适合查看行情、做盘面研究和辅助判断。

主要能力包括：

- ETH 现货与合约真实行情数据
- K 线、成交量、现货 CVD（累计成交量差）、合约 CVD（累计成交量差）
- OI（未平仓合约量）
- Funding（资金费率）
- 多空比
- 多周期研究数据，支持 14 个正式行情周期
- 数据质量检查，缺失、过期或低质量数据会明确提示，不用 0 值冒充正常数据
- Research Snapshot（研究快照）：把当前市场数据整理成统一研究上下文
- Quick AI（快速 AI 分析）：由用户主动触发，快速对当前市场状态进行辅助研究
- Agent（智能研究代理）深度研究：可在预算范围内进一步查看其它周期、历史数据和证据，再输出结构化研究结论
- 未来验证：把过去的研究结果放到未来真实行情中验证
- 准确率、MFE/MAE（最大有利/不利波动）等复盘指标
- Memory / Skill（经验与技能）沉淀：把经过真实验证的研究经验整理成可追溯的候选经验
- Cruise（巡航）事件引擎：程序规则持续观察价格、CVD、OI、资金费率、成交量及重大事件，满足条件后再触发深度研究
- 外部情报：整合新闻、ETF、宏观、交易所异常、安全事件、监管信息及部分 BTC 联动信息
- AI 模型统一路由、主备切换、健康检查与用量记录

**重要说明：本软件只提供研究、分析和辅助判断，不提供自动下单，不会替用户自动交易。**

### 2. 资源与搜索

- **资源合集**：统一整理常用网站、工具与资源入口
- **导航书签**：集中管理和快速打开常用网址
- **全网搜索**：一次输入关键词，聚合多个搜索来源
- **网盘全网聚合搜索**：用于查找公开网盘资源线索
- **AI 聚合搜**：一次输入，可同时发送到多个已选择的 AI 网页，并支持继续追问

### 3. 视频与内容下载

- **M3U8 下载**：自动发现网页或直链中的 M3U8 / HLS（流媒体播放列表），下载分片并合并为视频文件；支持多清晰度、TS / fMP4、音视频分离及标准 AES-128 加密流
- **YouTube 视频下载**：解析单个视频、选择真实清晰度、下载并自动合并音视频
- **抖音下载**
- **B站下载**
- **小红书图文 / 视频下载**

下载功能仅用于用户有权下载、保存或备份的内容；受第三方网站规则、页面变化和网络环境影响，个别平台能力可能随外部网站变化而调整。

### 4. 图片与视频处理

- **视频合并**
- **视频分割**：支持等分、固定时长、自定义分割点
- **视频压缩**：提供预设压缩、自定义压缩强度、批量队列、取消任务，并支持自动选择可用硬件加速
- **图片压缩**

媒体处理主要在本机完成，适合日常视频整理、体积压缩和文件处理。

### 5. 网络、局域网与设备

- **网络 / IP 工具**
- **一键 Ping（网络连通性测试）**
- **局域网共享设置**
- **局域网互传**
- **手机投屏**

适合家庭、办公室局域网中的文件互传、网络排查和手机画面投屏。

### 6. 日常效率工具

- **剪贴板工具**
- **一键打开网址**
- **倒计时 + 秒表**
- **电脑快捷键**
- **文件粉碎器**
- **信息流**
- **关于作者**

### 7. 客户端基础能力

- 软件版本检查与更新能力
- 本地备份、导入、导出
- 用户反馈入口
- 统一模块加载与故障隔离，单个功能异常尽量不影响整个客户端
- 运行环境检测与管理
- 客户电脑第一次启动时会自动展示一次运行环境检查；后续启动不再重复弹出，也可随时手动打开
- 安装版支持直接选择原安装目录覆盖升级，无需先卸载旧版；升级只替换程序自身文件，客户数据和其它未知文件保留
- 正式包采用统一模块封装，客户安装目录不暴露开发阶段的 Axxx 模块目录
- Windows 10 / Windows 11 64 位支持
